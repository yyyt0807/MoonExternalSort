# Third-party notices

MoonExternalSort is an original MoonBit implementation. No source code is copied or translated from another external sorting library.

The design uses standard published computer-science techniques: sorted Runs, stable position tie-breaking, binary-heap k-way merge and multi-pass external merge sorting. These algorithmic ideas are not treated as imported source code.

The project depends on the official `moonbitlang/async` package under its published license for Native filesystem and buffered I/O. Example records and test fixtures in this repository were created for MoonExternalSort and may be redistributed under the repository's Apache-2.0 license.
